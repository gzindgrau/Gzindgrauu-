# Gzindgrauu - Painel de Engajamento

Site focado em serviços e automações de engajamento para Instagram e redes sociais.

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido para apresentar e estruturar um site de divulgação e vendas de engajamento para perfis do Instagram.

## 🛠️ Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript

## 📌 Funcionalidades
* Divulgação de pacotes de engajamento
* Interface responsiva para celulares e computadores
* Links diretos para atendimento
